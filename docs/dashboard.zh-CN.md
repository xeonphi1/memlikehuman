# 离线记忆工作台

[首页](../README.md) · [English](dashboard.md) · [命令行参考](cli.zh-CN.md)

## 打开已有库

安装 Python 核心后运行：

```sh
memlikehuman --data-dir /ABSOLUTE/PATH/private-memory web
```

不指定 `--data-dir` 时使用默认目录或 `MEMLIKEHUMAN_HOME`。不自动开浏览器用 `web --no-browser`；固定端口用 `web --port 8765`。端口默认随机分配。请使用终端打印的完整链接，包含临时访问凭据；重启服务后旧凭据失效。按 Ctrl+C 停止服务。

这是本机 Python 服务加本地静态页面，不是双击 HTML 文件的无后端应用。依赖安装需要联网；安装后网页读写、搜索、手动提炼及文件导入导出均不联网。即使已配置云端 API，网页也不会调用它。

## 一次完整操作

1. 选左侧记忆库、人格／项目，再选分层。
2. 点击记录查看详情。提炼记忆可展开来源原文、有效期及同来源版本。
3. 修改后点“保存新版本”。核心人格和提炼记忆保留旧版本；工作交接新增记录。
4. 从“原始经历”进入原文，选择“从这段原文新增提炼记忆”，填类别、内容、原话和陈述类型。人工提炼不调用模型；引文必须原样存在，来源角色与陈述类型必须一致。
5. 点“导出与备份”，选择 JSON、JSONL 或 SQLite，将修改后的完整库下载到本地。

## 各层编辑规则

- **人格**：名称、性格、价值观、表达风格和边界。数组每行一条。同一个人格跨项目共享，详情可将旧版本恢复为新的当前版本。
- **原始经历**：可以新增原文，或保存有来源的参考修订副本。原始事件不被覆盖，已提炼记忆不会自动按副本重写；需要到相应层明确修改。副本不会被当作真实历史对话提炼。
- **事实、偏好、约定、成长、经历、观察**：可改内容、概览和置信度。来源原话、来源事件、类别、陈述类型与有效期保持不变。修订是对现有证据的解释调整；真正发生事实变化时应新增带准确时间的原始事件，使用 CLI 提炼并设置 `subject` / `fact_key` / `valid_at` 来维护时间线。
- **情绪**：可改内容、概览、置信度、方向（−1～1）及强度（0～1）。仍引用原始助手表达，沿用原时间衰减，不会将旧情绪重新设为当前状态。
- **工作交接**：目标、完成项、待办、约束、下一步。覆盖事件 ID 必须属于所选分区和会话。编辑提炼记忆或删除原文后，当前分区旧交接会清理，需重新保存。

列表每页 20 条；搜索只匹配当前层的文字，不使用语义 API。人格层显示最近版本，每页 20 个版本，不做文本搜索。后台列表仅返回短预览，详情按需读取原文；大量记录的计数及子串搜索仍可能随数据量增长。

## 导入和导出

| 格式 | 网页行为 |
|---|---|
| MemLikeHuman JSON | 完整版本化记忆包 |
| MemLikeHuman JSONL | 带 header 和 table/row 的逐行记忆档案 |
| SQLite 备份 | 数据库一致性快照；导入后重建可丢弃索引 |
| 平台原始聊天 JSON/JSONL | 不直接支持，先走[历史迁移](history-migration.zh-CN.md) |

导入会校验结构、来源关系及分区，再创建独立库。原有库不会合并或覆盖。单文件限 64 MiB；导出不限该上传大小，但仍在内存组装文件。非常大的库推荐 CLI 备份，避免浏览器占用过多内存。

导出范围为**整个选中库的所有人格与项目**，不受当前筛选影响。人格版本、原始事件、派生记忆、关系、情绪、交接和宿主捕获游标均保留。JSON/JSONL 不包含配置及向量缓存；SQLite 备份包含库内索引。API 密钥配置不会进入导出包，原文中的私人内容不会自动脱敏。

导入库保存在主数据目录的 `dashboard-libraries/<id>/`。底部显示实际路径。将 MCP / Harness 的 `--data-dir` 指向此路径并重启后，模型才会使用该导入库。主库备份不会自动包含其他独立导入库，请分别导出。

## 删除与隐私

“删除及关联记忆”沿用 `memory_forget` 的级联行为：删除来源事件、该事件的全部派生记忆及相连纠错链，并清理索引及当前分区交接。这是永久删除，页面会先说明影响并要求确认。历史导出、独立修订副本、其他库与提供商日志不会随之删除。

只监听 `127.0.0.1`，每次启动生成临时访问 token。API 校验 token、Host 和 Origin；页面使用限制性 CSP，并把记忆内容作为纯文本渲染。不要把服务通过反向代理、端口转发或共享链接公开给别人。它不是多用户权限系统；数据未做本地加密。

## 常见问题

**页面提示重新打开完整链接：** 使用当前终端打印的地址；旧 token 不能跨服务重启使用。不要只复制端口号。

**编辑后模型没看到：** 核对网页底部路径与 MCP `--data-dir`、人格和项目是否一致。已在模型上下文中的旧文字不会自动刷新，需重新 recall/resume。

**导入失败：** 确认是本项目的版本化档案，JSONL 包含 header，而不是逐条聊天事件文件。格式错误时独立导入目录不会发布。

**需要重算语义索引：** 网页编辑会使相关旧向量失效，新版本未自动生成向量。若使用语义检索，请在配置好提供商后单独运行 `reindex`，该操作可能联网。

**Windows 路径：** 可使用 `C:/Users/name/private-memory`。服务和网页资源都打包在 Python wheel 中，不需要 npm 来运行面板。
